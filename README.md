# Yandex SmartCaptcha

Moodle local plugin `local_yandexcaptcha`.

Integrates Yandex SmartCaptcha into Moodle forms as an alternative to reCAPTCHA.

## Requirements

- Moodle with version number `2022112800` or later.

## Installation

Copy the plugin folder to `local/yandexcaptcha` in your Moodle root, then visit
**Site administration → Notifications** to complete the database upgrade.

```
<moodle>/local/yandexcaptcha
```

## Version

Release `1.0.5`. See `version.php` for the exact version number.
